## 📝 1. ภาพรวมของโปรเจค (Project Overview)

**Thesis Chatbot** เป็นนวัตกรรมระบบแชทบอทอัจฉริยะที่ถูกออกแบบมาเพื่อช่วยเหลือนักศึกษาและบุคลากรในภาควิชาคอมพิวเตอร์ มหาวิทยาลัยศิลปากร ในการสืบค้นและดึงข้อมูลความรู้จากเล่มปริญญานิพนธ์ (Thesis) รุ่นก่อน ๆ ได้อย่างมีประสิทธิภาพ 

ระบบทำงานภายใต้สถาปัตยกรรม **Retrieval-Augmented Generation (RAG)** โดยผสานการทำงานระหว่างระบบค้นหาความหมายจากฐานข้อมูลเวกเตอร์แบบออฟไลน์ (FAISS) และโมเดลภาษาขนาดใหญ่ (Typhoon LLM) ทำให้บอทสามารถอ่าน สกัด และสรุปเนื้อหาจากเอกสาร PDF ของปริญญานิพนธ์เพื่อตอบคำถามผู้ใช้แบบเจาะจงบทและหัวข้อได้อย่างแม่นยำ เป็นธรรมชาติ และอ้างอิงได้จริง

## ✨ 2. รายละเอียดฟังก์ชันการทำงาน (Core Features)

ระบบได้แบ่งการทำงานและฟังก์ชันออกเป็นหลายส่วน เพื่อตอบสนองทั้งมุมมองของผู้ใช้งานทั่วไปและผู้ดูแลระบบ:

### 🔐 2.1 ระบบยืนยันตัวตน (Authentication)
- **Google OAuth2 Integration:** ควบคุมการเข้าถึงระบบอย่างเข้มงวด โดยอนุญาตให้ล็อกอินเข้าสู่แอปพลิเคชันได้เฉพาะผู้ใช้ที่มีอีเมลโดเมนของมหาวิทยาลัยศิลปากร (`@silpakorn.edu`) เท่านั้น

### 🧠 2.2 ระบบวิเคราะห์เจตนา (Intent Classification & Router)
ระบบสามารถวิเคราะห์เจตนาของประโยคที่ผู้ใช้พิมพ์เข้ามา และส่งต่อไปยัง Module การประมวลผลที่ถูกต้อง รองรับ 8 สถานการณ์หลัก:
1. **Ranking (`ranking`):** ค้นหาและจัดอันดับรายชื่อโปรเจคตามคีย์เวิร์ด ปี พ.ศ. หรือความสนใจ
2. **Download (`download`):** ค้นหาและสร้างลิงก์สำหรับดาวน์โหลดไฟล์ต้นฉบับ PDF ของงานวิจัยที่ต้องการ
3. **Metadata Query (`metadata_query`):** ดึงข้อมูลผู้จัดทำ ปีการศึกษา หรืออาจารย์ที่ปรึกษาของโปรเจคนั้น ๆ
4. **Deep Document Q&A (`answer_based_on_documents`):** ฟังชัน RAG ที่วิเคราะห์เจาะลึกไปถึงเนื้อหา "ภายใน" เล่ม เช่น ขอให้สรุปเนื้อหาในบทที่ 3 ของเอกสาร
5. **Lecturer Info (`lecturer_info`):** ดึงข้อมูลขอบเขตความเชี่ยวชาญ และช่องทางติดต่อของอาจารย์แต่ละท่าน
6. **Project Advice (`project_advice`):** ให้ AI ทำหน้าที่เป็นกุนซือช่วยเบรนสตรอม (Brainstorm) หรือเสนอไอเดียหัวข้อเทคโนโลยีใหม่ ๆ สำหรับทำปริญญานิพนธ์
7. **Advisor's Projects (`advisor_projects`):** แสดงรายชื่อโปรเจคทั้งหมดที่อาจารย์ที่ผู้ใช้ระบุเป็นผู้ควบคุมหรือให้คำปรึกษา
8. **Chitchat (`chitchat`):** โต้ตอบพูดคุยทักทายทั่วไปอย่างเป็นธรรมชาติ

### ⚙️ 2.3 ระบบจัดการข้อมูลพื้นที่หลังบ้าน (Admin Dashboard & Data Processing)
- **Bulk PDF Upload:** ระบบรองรับการอัปโหลดไฟล์ PDF พร้อมระบุ Metadata ได้หลายไฟล์ในครั้งเดียว 
- **Auto Text Extraction & Thai NLP Correction:** เมื่ออัปโหลดไฟล์ ระบบจะใช้ `pdfplumber` ดึงข้อความ และรันผ่านสคริปต์แก้ไขปัญหาสระ/วรรณยุกต์ภาษาไทยที่มักเด้งหรือผิดเพี้ยนจากไฟล์ PDF (ควบคุมด้วย Regex และ Dictionary) อย่างไร้รอยต่อ
- **Automated Chunking & Embedding:** ข้อความที่คลีนแล้วจะถูกหั่นเป็นส่วนย่อย (Chunks ขั้นละ ~2000 token) นำไปผ่านการประมวลผลให้เป็นเวกเตอร์ขนาด 384 มิติ และจัดเก็บลง FAISS Index โดยอัตโนมัติ
- **CRUD Operations:** เมนูย่อยสำหรับจัดการเพิ่ม ลบ หรือแก้ไขข้อมูลบัญชีรายชื่อและความเชี่ยวชาญของอาจารย์ประจำภาค

## 🏗️ 3. โครงสร้างและคำอธิบายไฟล์ในระบบ (Project Structure)

```text
THESIS_CHATBOT/
│
├── api/
│   └── typhoon_api.py          # [Module] หน้าที่จัดการ HTTP Requests สื่อสารกับ Typhoon LLM API เบื้องหลังด้วยพรอพท์ระบบ
│
├── instance/
│   ├── db.sqlite3              # [Database] ไฟล์ฐานข้อมูล Relation (จัดเก็บ Metadata โครงงาน และอาจารย์)
│   └── faiss_index             # [Database] ไฟล์ Vector Database เก็บข้อมูลตัวอักษรที่แปลงเป็นจุดพิกัดในรูประบบ FAISS
│
├── static/
│   ├── uploads/                # [Storage] ไดเรกทอรีจัดเก็บไฟล์ PDF ต้นฉบับ (เก็บเพื่อให้ User ดาวน์โหลดต่อไป)
│   └── logo.png                # [Asset] ไฟล์ภาพโลโก้ของระบบ
│
├── templates/                  # [Views] ไฟล์ UI หน้าเว็บทั้งหมดเขียนด้วย HTML (เชื่อมต่อผ่าน Jinja2)
│   ├── admin_*.html            # ชุดหน้าต่างสำหรับ Admin ใช้แก้ข้อมูลโปรเจคและฟอร์มอัปโหลดไฟล์
│   ├── chat.html               # หน้าต่างอินเตอร์เฟซหลักของ Chatbot สำหรับผู้ใช้งาน
│   ├── how_to_use.html         # หน้าเว็บคู่มือการใช้งานระบบและการตั้งค่าคำถามสำหรับผู้ใช้ใหม่
│   ├── lecturers_*.html        # หน้าต่างตารางจัดการรายชื่ออาจารย์ (สำหรับ Admin)
│   └── login.html              # หน้าแรกสุดเพื่อบังคับทำการ Login ผ่านระบบ Google OAuth
│
├── utils/                      # [Controllers/Logics] แฟ้มรวมฟังก์ชันประมวลผลและการจัดการข้อมูลแกนหลัก
│   ├── intent_classifier.py    # สคริปต์วิเคราะห์คำสั่ง (ส่ง Prompt ไปถาม LLM ว่าประโยคนี้จัดอยู่ในเจตนาใดใน 8 ข้อ)
│   ├── pdf_utils.py            # สคริปต์สกัดข้อความ, ซ่อมแซมสระภาษาไทยที่ผิดรูป และทำความสะอาดตัวเลขของแต่ละหน้า
│   └── vector_utils.py         # กลไกตัดแบ่งคำด้วย pythainlp(attacut), การนำ Chunk มาทำ Embedding Vector ด้วย SentenceTransformer และค้นหากลับ (Similarity Search)
│
├── app.py                      # [Main] ไฟล์ควบคุมแอปพลิเคชัน Flask หลัก (รวม Routing, คุม Pipeline ของ RAG และ Session)
├── config.py                   # [Config] รวม Environment Variables, API Keys, ตำแหน่ง Path ไปยัง DB และ PDF
├── opendb.py                   # [Tool] มินิเซิร์ฟเวอร์แยก (Port 5001) สำหรับรันหน้าต่างแก้ไขตารางข้อมูลใน SQLite ได้โดยตรง
└── requirements.txt            # [Dependencies] รายการไลบรารี Python ทั้งหมดที่จำเป็นต้องการใช้งาน
```

## 🛠️ 4. สถาปัตยกรรมและเทคโนโลยีที่เลือกใช้ (Tech Stack)

### 💻 Backend & Core Framework
- **Python / Flask**: โครงสร้างหลักในการรันเว็บแอปฯ และเชื่อมต่อ HTTP API ต่างๆ
- **SQLite / Flask-SQLAlchemy**: ระบบบันทึกและจัดการฐานข้อมูลเชิงสัมพันธ์น้ำหนักเบา

### 🤖 AI, LLM & Embedding Models
- **Generative AI:** `Typhoon API` (โมเดล `typhoon-v2.1-12b-instruct`) สำหรับวิเคราะห์ภาษาและสังเคราะห์คำตอบชั้นปลาย
- **Embedding Model:** `sentence-transformers` (ใช้รูปแบบแปลภาษา `paraphrase-multilingual-MiniLM-L12-v2`) สำหรับแปลงชุดข้อความเป็นเวกเตอร์ภาษามิติสูง
- **Vector Search Engine:** `FAISS (Facebook AI Similarity Search)` ดัชนีหลักสำหรับประมวลผลค้นหาความคล้ายคลึงของข้อความด้วยความเร็วสูงและแม่นยำ

### 🇹🇭 Text Processing & NLP
- **PDF Parsing:** `pdfplumber` 
- **Thai NLP:** `pythainlp` (ใช้ engine ตัดคำแบบ `attacut` ช่วยหั่นประโยคแบบผู้เชี่ยวชาญภาษาไทย)

## 🚀 5. วิธีการติดตั้งและรันโปรเจค (Installation Guide)

### สิ่งที่ต้องเตรียมตัวก่อนรัน (Prerequisites)
1. ติดตั้ง **Python 3.10** หรือสูงกว่าลงเครื่อง
2. สมัครใช้งาน และสร้างโปรเจคเพื่อเอาคีย์ **Opentyphoon API Key**
3. เตรียม OAuth API: ไปที่ **Google Cloud Console** เพื่อขออนุญาต `OAuth 2.0 Client ID` สำหรับล็อกอิน (กำหนด Authorized redirect URI เป็น `http://127.0.0.1:5000/callback`)

### ขั้นตอนการรันระบบในโหมดนักพัฒนา
1. **โคลงโปรเจคและดาวน์โหลด Source Code:**
   ```bash
   git clone <REPOSITORY_URL_ที่นี่>
   cd thesis_chatbot
   ```

2. **สร้างพื้นที่จำลอง Environment (เพื่อไม่ให้ไลบรารีตีกับระบบเดิม):**
   ```bash
   python -m venv .venv
   
   # สำหรับเครื่อง Windows:
   .venv\Scripts\activate
   # สำหรับเครื่อง macOS/Linux:
   source .venv/bin/activate
   ```

3. **ติดตั้งแพ็กเกจไลบรารีที่จำเป็นผ่าน PIP:**
   ```bash
   pip install -r requirements.txt
   ```

4. **ตั้งค่า Config:**
   แก้ไขค่าในสคริปต์ `config.py` เพื่อระบุ API Key และตัวแปรต่าง ๆ:
   ```python
   TYPHOON_API_KEY = "YOUR_TYPHOON_API_KEY"
   GOOGLE_CLIENT_ID = "YOUR_GOOGLE_CLIENT_ID"
   GOOGLE_CLIENT_SECRET = "YOUR_GOOGLE_CLIENT_SECRET"
   ```

5. **เปิดรันเซิร์ฟเวอร์หลักของแอปพลิเคชัน:**
   ```bash
   python app.py
   ```
   *ใช้งานระบบหลักผ่านเบราว์เซอร์: `http://127.0.0.1:5000`*

6. **ระบบจัดการฐานข้อมูล (ทางเลือกเสริม):**
   หากต้องการเข้าไปแก้ไขข้อมูลดิบในตารางปริญญานิพนธ์ (เผื่อพิมพ์ตกหล่น) สามารถรันเซิร์ฟเวอร์ทางเลือกเพื่อทับพอร์ต:
   ```bash
   python opendb.py
   ```
   *หน้าต่างแก้ไขข้อมูลดิบพร้อมทำงานที่เบราว์เซอร์มุมมอง: `http://127.0.0.1:5001`*

## 🎯 6. บทสรุปความสามารถของโปรเจค (Project Capabilities Summary)

**Thesis Chatbot** เป็นมากกว่าช่องค้นหารายชื่อแบบเดิมๆ รูปแบบเก่า แต่เป็นการประยุกต์ใช้ **AI สมัยใหม่ (Generative AI & Retrieval-Augmented Generation)** เพื่อปฏิวัติและพลิกโฉมวิธีการเข้าถึงความรู้และผลงานวิจัยของคณะ โปรเจกต์นี้ถือกำเนิดขึ้นเพื่อแก้ปัญหา Pain Point หลักของนักศึกษาและการทำงานของบุคลากรได้อย่างครบถ้วน 

- **ทะลวงข้อจำกัดการค้นหาด้วย RAG:** ผู้ใช้งานไม่ต้องเสียเวลาสุ่มเปิดอ่าน PDF ขนาดหลายร้อยหน้าทีละเล่มอีกต่อไป ระบบสามารถ "กวาดสายตาอ่านเนื้อหาทุกหน้าด้วยเวกเตอร์" และดึงเฉพาะ "เนื้อหาเชิงลึก/บทที่เกี่ยวข้อง" ออกมาสรุปตอบเป็นประโยคย่อให้ผู้ใช้ได้ทันทีในไม่กี่วินาที
- **ความแม่นยำและการอ้างอิงตรงกระเด็น (No Hallucination):** ต่างจาก Chatbot ทั่วไปตรงที่การหาข้อมูลถูกจำกัดวงเฉพาะอยู่ภายในข่ายงานวิจัยของมหาวิทยาลัยฯ จริง ๆ จึงตอบคำถามได้อย่างไม่มั่วซั่ว และมั่นใจได้
- **ผู้ช่วยส่วนตัวสำหรับรุ่นน้อง:** ระบบรวมการค้นหาอาจารย์ที่ปรึกษาที่รับผิดชอบและสอดคล้องกับความสนใจ ไปจนถึงช่วยบอทคิดหัวข้อโปรเจค (Brainstorm) ช่วยลดช่วงเวลาวิกฤติตอนเริ่มทำโครงงานของนักศึกษาชั้นปีสุดท้ายได้อย่างมีนัยสำคัญ
- **ดูแลรักษายั่งยืนและง่ายดาย:** แอดมินและอาจารย์มีเครื่องมือในการอัปโหลดเอกสาร PDF ลงฐานระบบเบื้องหลังได้อย่างง่ายดาย
